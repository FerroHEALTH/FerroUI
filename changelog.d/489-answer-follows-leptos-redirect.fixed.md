- `widget::action::draw_answers` follows a server function that calls `leptos_axum::redirect` during a plain post of an answer form. Under the forwarded `Accept: */*` that call answers `200` with `Location` and the `serverfnredirect` header, which the wrapper used to draw as the form's page with no answer; it now answers `303 See Other` to that `Location`, with the cookies the function set. A console that answered `303` itself to work around this can call `leptos_axum::redirect` again.
