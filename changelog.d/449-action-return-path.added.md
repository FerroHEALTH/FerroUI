- `widget::action` carries the page a console's `<ActionForm>` returns to with no WebAssembly in the form: `return_field()` draws the hidden `ferroui_return` field, and the server function redirects a plain post to `plain_return()`, a path on the console's own origin, or to `with_error()`, which adds the error the router reads into the action's value. Before, server_fn sent the post back to the `Referer`, which every console's `no-referrer` policy withholds, so the browser landed on `/`.
