- `view::template::settings::ValueSource::CommandLine`, "From the command line" with the keyboard glyph, marks a settings row whose value a `--set key=value` argument set at start, which wins over the environment, the file and a revision. A console built on `ferrohealth-server` maps the command-line layer `ferrohealth-config` reports to it in place of drawing the row unmarked. `ValueSource` is `#[non_exhaustive]`, so no console's code breaks; the message `setting-source-command-line` joins the library's `templates` catalog.
